Heap-Based Leaderboard Ranking

To rank suspicious accounts in real-time, the system utilizes a **Custom Binary Max-Heap** (`MaxHeap` class in C++).

Why not sort?

Sorting the entire user list takes O(N log N) time. A Max-Heap allows us to dynamically retrieve the most suspicious user in O(1) time, and insert/update in O(log N) time. This represents a massive performance optimization for real-time systems.
